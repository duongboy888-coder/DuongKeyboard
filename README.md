# DuongKB – Bàn phím Android

Bàn phím Android viết bằng Java thuần, không cần thư viện ngoài.

## Tính năng
- QWERTY + 2 trang số/ký hiệu
- Shift (chạm đúp = Caps Lock), tự viết hoa đầu câu
- Giữ ⌫ để xoá liên tục
- Giữ phím cách để đổi bàn phím
- Phím Enter tự thành Gửi/Tìm/Tiếp tuỳ ô nhập
- Ô nhập số tự mở trang số
- Rung khi gõ, giao diện tối

## Build
Mỗi lần push lên nhánh `main`, GitHub Actions sẽ tự build.
Vào **Actions → lần chạy mới nhất → Artifacts → DuongKB-apk** để tải APK.

## Cài đặt
1. Cài APK, mở app DuongKB
2. Bấm "Bật bàn phím" → bật DuongKB
3. Bấm "Chọn bàn phím" → chọn DuongKB
